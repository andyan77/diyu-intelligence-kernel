# 推进流程（薄编排：只引用不复述，一切细节以文档为准）

1. **读宪法与台账**：`CLAUDE.md`（六条北极星 + 三铁律 + 协作契约）、`裁决台账.md`。
2. **开工两查**（不通过不得开工）：
   a. 抽查台账"已落盘"条目的落盘位置真实存在（文件+章节能找到）；发现悬空 → 先补落盘并报告；
   b. 检查"挂起"表中触发节点已到期的项、"待 Founder 裁决"表中阻塞当前工作的项 → 主动浮现给 Founder，未决先决。
3. **定位**：读 `D_MVP执行框架与执行包索引.md` 确定当前 Gate 与下一个执行包；排期对照 C.9。
4. **提出执行包**：向 Founder 报告本次要做什么、动哪些文件、验收挂哪个 Gate/PRE/案例编号；等确认（doc-only ≤3 文件小活按既有持久授权可直接执行到位）。
5. **执行纪律**：遵守 C 方案（三区制隔离 / 尝试账本 / 断言门控 / 熔断锁）与宪法三铁律（不猜 / 不假绿 / 不加建）。Founder 新需求一律先过协作契约四选一处置。
6. **收口**：输出"本次裁决与落盘对照表"；新增裁决与挂起项登记进 `裁决台账.md`。
