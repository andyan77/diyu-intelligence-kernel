# 周报生成（结论先行，一页以内，禁止编造数字）

1. 读 `裁决台账.md`：统计三态数量；逐条列出"待 Founder 裁决"与已到期的"挂起"项。
2. 读 `D_MVP执行框架与执行包索引.md`：定位当前 Gate、进行中/已完成的执行包。
3. 若 `tools/coverage.py` 已存在：运行并取 C.7 五数字；**不存在则如实写"构建未启动，工程指标待建"，禁止填充任何估算值**。
4. 输出格式：
   - 一句话总结（在推进 / 停滞 / 等裁决）；
   - 当前位置（Gate + 执行包）；
   - 台账三态表 + 等你裁决的 N 件事（置顶）;
   - 工程五数字（有则列，无则注明待建）；
   - 异常信号（连续两周数字不动 = 原地打转警报）。
