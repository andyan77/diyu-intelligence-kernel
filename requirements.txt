# PyYAML 钉版变更史（防假绿留痕，2026-08-17 本批次）：
#   曾钉 5.4.1（理由：本机 `import yaml` 实测现值）。实测该值在干净环境下**装不上**——
#   5.4.1 无 cp310 wheel，pip 回落源码构建后 `AttributeError: 'build_ext' object has no
#   attribute 'cython_sources'`（新版 Cython 与其 setup.py 不兼容），
#   `python3 -m venv → pip install -r requirements.txt` 直接 exit 1。
#   之所以本机"看着有 5.4.1"，是因为它是 apt 系统包（/usr/lib/python3/dist-packages，
#   带 egg-info 而非 dist-info）——那条 pin 从未经过 pip 实测，属"版本号看着对"的假绿。
#   现钉 6.0.2（有 cp310 manylinux wheel），并已在干净 venv 实跑 `pip install -r requirements.txt`
#   → exit 0，随后用该 venv 解释器重跑 tools/check_m0.py 五步全绿、重出 RUN-000x / coverage 证据。
#   不放宽成 `>=`：放宽等于"证据在哪个版本下取得的"这句话失去答案。
#   注意：若本机 python3 仍是 apt 的 PyYAML 5.4.1，check_m0 的环境行会打印一条漂移提示——
#   那是设计内的诚实提示（提示不改判绿）；要与证据同条件复跑，请在钉版 venv 里跑。
#
