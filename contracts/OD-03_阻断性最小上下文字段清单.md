## 一、通用阻断项（任何任务缺一即停，BLOCKING）

| # | 字段（大白话） | A 对应 |
|---|---|---|
| 1 | 做哪个商品：至少选定一个且在库 | `selected_product_refs`（A.4.1：至少一个） |
| 2 | 为什么做：商业目标已解析（七枚举之一）。「推广／做内容」类表述＝正常解析为 DAILY_CONTENT_OPERATION（日常内容经营）继续，不把目标选择题抛回用户；仅当用户**明示了**某个经营意图但表述落不到枚举时才问；六个特殊经营目标不得擅自选定（听不出来必须问，不许猜——管辖范围收窄至此） | `business_goal`（A.5.2：goal_resolution=RESOLVED 才可继续；A.2.6 v0.4 七枚举） |
| 3 | 哪个品牌：品牌身份明确（防串牌） | `brand_id`（SYS-08 单品牌隔离） |

## 二、分目标追加阻断项（在通用四件之上）

| BusinessGoal | 缺了就停的字段 |
|---|---|
| DAILY_CONTENT_OPERATION 日常内容经营 | （无追加阻断项——通用四件齐即做；人设／受众／材质凭证等照 §三 非阻断处理，交付后提示补充） |
| INVENTORY_ACTIVATION 库存激活 | 库存数量与有效性；时间窗口（多久内消化）；品牌促销边界（最低折扣线 / 禁用表达）——**促销边界为条件阻断：仅用户明示促销／清库存／折扣意图（含明示本目标）时 BLOCKING；未明示时不阻断，降为交付后可选提示（v1.1，Founder 判分批）** |
| PRODUCT_LAUNCH 新品推广 | 商品已确认卖点或可验证事实（成分 / 版型）；在售状态 |
| CONVERSION 转化 | 价格（无价或价格冲突未解决即停）；在售 / 购买渠道 |
| BRAND_STORY 品牌故事 | 品牌定位与价值主张；主理人人设事实（G.1 窄门：必须有品牌锚） |
| CUSTOMER_EDUCATION 用户教育 | 教育点对应的可验证商品事实（如成分 / 护理）；无真源事实不得编功效 |
| BRAND_AWARENESS 品牌认知 | 品牌定位；说话调性；禁用表达清单 |

## 三、非阻断项（QUALITY_REDUCING，快速模式可跨过）

人设 / 账号事实（缺 → 暂定人设标 ASSUMPTION、降 confidence、不得编造创始人背景——INT-D02）；受众调研；材质证明（除非涉及功效声明，届时升为对应目标的阻断项）；次要商品字段（如里料）；品牌促销边界（用户未明示促销／清库存／折扣意图时——v1.1：此时属交付后可选提示，不得作执行前障碍）。

## 四、两条通用规则（照抄 A.4.2，不另造）

1. QUICK 只能跨过 QUALITY_REDUCING 缺失；每跨一项必须产生 ASSUMPTION 和 confidence 限制；
2. 字段 availability=CONFLICTING（如双价）视同缺失处理，且内容不得使用该字段值。
